## Como usar

1. Baixe e abra o **FluxDesk.exe**. Não precisa instalar.
2. Informe ao técnico da Flux o **ID de 9 dígitos** que aparece na tela.
3. Quando o técnico pedir acesso, clique em **Aceitar**.
4. Para encerrar, clique em **Encerrar** no painel "sessão ativa".

Enquanto alguém estiver conectado, o painel **"sessão ativa"** fica sempre visível, mostrando quem está acessando.

## Aviso do Windows

Na primeira vez, o navegador ou o Windows pode avisar que o arquivo não é comum. Nesse caso:
- **No navegador:** clique em **Manter**.
- **Na tela "O Windows protegeu o computador":** clique em **Mais informações → Executar assim mesmo**.

## Segurança

- **Ninguém acessa sem você aceitar,** a menos que você mesmo defina uma senha de acesso.
- **A conexão é criptografada de ponta a ponta** entre o seu computador e o do técnico.
- **Só técnicos com licença da Flux** conseguem acessar outros computadores.
